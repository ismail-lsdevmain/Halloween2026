## ✨ Features & Modules

### 1. 🎃 Jack-O'-Carver Studio
* **Interactive Pumpkin Sculpting**: Freehand carving with customizable carving knife, gouge, and patch eraser tools.
* **Spooky Stencils**: Instant stamp templates (*😈 Wicked Grin, 🧛 Vampire Fangs, 📐 Classic Evil Triangles, 🦇 Shadow Bat, 😱 Screaming Ghoul, 🐱 Hex Cat*).
* **Flickering Inner Candle**: Dynamic candle simulator with multiple flame colors (*Amber Flame, Toxic Slime, Phantom Violet, Blood Crimson, Ghostly Frost*).
* **Save & Export**: Download your completed carved Jack-O'-Lantern directly as a PNG.

### 2. 🧪 The Witch's Alchemical Cauldron
* **Interactive Ingredient Pantry**: Drag & drop or click 8 bewitched ingredients into the ancient iron cauldron (*Eye of Newt, Vampire Blood, Ectoplasm Vial, Ghostcap Shroom, Widow Venom, Lich Bone Dust, Bat Wing Essence, Nightshade Petal*).
* **Bubbling Liquid Canvas**: Real-time bubbling particles, surface liquid physics, and dynamic steam bursts.
* **Arcane Grimoire**: Discover secret recipes and unlock ancient spells in your spellbook.

### 3. 🔮 The Haunted Oracle & Spirit Sanctum
* **3D Tarot of Shadows**: 3-card destiny reading (*Past Haunting*, *Present Specter*, *Future Doom*) featuring 12 Major Arcana cards with smooth 3D perspective card flips and spooky lore.
* **Interactive Ouija Spirit Board**: Type your question or pick spooky presets; watch the spectral planchette smoothly glide across the wood board to light up letters and whisper answers from beyond.

### 4. 🦇 Graveyard Bash (Crypt Slayer Minigame)
* **Whack-a-Ghoul Arcade Action**: Fast-paced 30-second reflex hunt whacking popping ghosts, pumpkins, and bats.
* **Combo Streaks**: Build consecutive hits to unlock **x2, x3, and x5** score multipliers.
* **Cursed Traps**: Avoid popping Cursed Skulls (💣) that dock points and break combo streaks!
* **High Score Tracking**: Automatically saves your record in `localStorage`.

### 5. 🔊 Procedural Crypt Soundboard
* **100% Web Audio Synthesized**: Zero external audio downloads needed!
* **12 Spooky Sound Presets**:
  * ⚡ Thunder Crash (Pink noise lightning sweep)
  * 🐺 Werewolf Howl (Modulated formant vocal)
  * 👻 Ghostly Wail (Dual detuned sine pitch glide)
  * 🧙‍♀️ Witch Cackle (Staccato resonant burst)
  * 🚪 Creaky Dungeon Door (FM friction groan)
  * ⛓️ Phantom Chains (Metallic resonant cluster)
  * 🎹 Cathedral Organ (Minor chord sawtooth swell)
  * 💓 Haunted Heartbeat (Low frequency double thump)
  * 🦇 Bat Swarm (Fluttering ultrasonic bursts)
  * 💀 Skeleton Bones (Percussive woodblock clatter)
  * 🎠 Creepy Music Box (Chilling bell-toned lullaby)
  * 🔪 Jump-Scare Sting (Dissonant high tension chord)
* **Real-time Audio Visualizer**: Top frequency visualizer reacting live to all sound effects.

### 6. 🎭 Monster Morph: Halloween Persona Generator
* **Supernatural ID Badge**: Generates official "All Hallows' Sanctum" identification passes with holographic strip, monster species, haunted elements, and spooky zodiac signs.
* **Stats Radar**: Spookiness, Candy Greed, and Night Vision meters.
* **Shareable**: Copy your generated monster card stats directly to your clipboard.

### 7. 🌌 Atmosphere, Moods & Countdown
* **Halloween Countdown Timer**: Real-time ticker counting down to midnight on All Hallows' Eve.
* **Atmospheric Canvas**: Flapping bats with sinusoidal flight physics and mouse evasion, plus floating glowing embers.
* **4 Atmospheric Moods**:
  1. 🎃 *Pumpkin Twilight* (Vibrant Orange & Violet)
  2. 🧪 *Toxic Graveyard* (Acid Slime Green & Crypt Slate)
  3. 🩸 *Blood Eclipse* (Vampire Crimson & Midnight Obsidian)
  4. 👻 *Phantom Mist* (Spectral Cyan & Frost Ethereal)
* **Summon Thunder**: Triggers a screen-shaking double lightning flash with synthesized thunder!

## 🚀 Quick Start / Local Setup

Clone the repository:
```bash
git clone https://github.com/ismail-lsdevmain/Halloween2026.git
cd Halloween2026
```

Open `index.html` in any modern web browser, or launch a local server:

Using Python:
```bash
python -m http.server 5173
```

Using Node.js:
```bash
npx serve .
```

Then visit `http://localhost:5173/` in your browser.

## 🛠️ Tech Stack

- **Markup**: Semantic HTML5 with accessibility tags and SEO meta descriptions
- **Styles**: Modern Vanilla CSS (CSS Custom Properties, Glassmorphism, 3D Transforms, Responsive Grid/Flexbox)
- **Audio Engine**: Web Audio API (Oscillators, BiquadFilters, GainNodes, Real-time Analyser)
- **Graphics & FX**: HTML5 2D Canvas (Physics-based particle system, composite masks, image generation)
